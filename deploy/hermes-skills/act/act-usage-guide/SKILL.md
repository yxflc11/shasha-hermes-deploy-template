# ACT Usage Guide

目标不是让 使用者学一套命令，而是在卡住时告诉他“下一句可以直接说什么”。不调用工具、不修改 ACT，也不把帮助请求保存成日志。

## 无明确上下文时

用下面格式给最多 6 个入口；每项都写成可直接发送的示例：

```markdown
你现在可以直接回复：

- `开始今天` — 看今日上下文、时事和 AIHOT，再确定一件重点
- `今天 AI 圈有什么` — 单独看 AIHOT
- `今日时事` — 单独看通用新闻
- `整理这篇 <文章链接>` — 先整理，不自动保存
- `记一下 <你的原话>` — 原文暂存，稍后受控同步
- `收尾今天` — 用几个短问题完成今日回顾

不知道选哪个，就回复：`开始今天`
```

## 有明确流程时

只给当前相关选项，不重复完整菜单：

- 每日开场问今日重点后：`今天先完成___` / `我有几件事，帮我选` / `先从 ACT 给我 3 个候选`。
- 07:00 定时简报后：`今日重点：___` / `帮我从 ACT 里选` / `今天先不规划`。不要建议再次说“开始今天”，以免重复新闻。
- 19:00 定时简报后：`今日收尾：推进___；学到___；卡点___；明天___` / `帮我一步步回顾` / `今天不保存`。
- AIHOT 列表后：`展开第 N 条` / `核验第 N 条` / `只看和我有关的` / `今天先到这里`。
- 普通文章整理后：`收下这篇` / `继续问：___` / `不保存`。
- 提示词链接整理后：在 Prompt 尚未暂存时展示 `1. 收下这个提示词` / `2. 把完整提示词给我看` / `3. 不保存`，允许 使用者只回对应的单个数字。数字只在紧接该菜单时有效，不得套用到其他菜单或已暂存对象。
- 查询知识库提示词后：`把完整提示词给我` / `对比这几条` / `换一个需求：___`。
- 收尾预览后：`确认收尾` / `修改：___` / `今天不保存`。
- 暂存完成后：明确当前聊天阶段已经完成，并提示回到 Mac/Codex 说 `同步日志` 或 `同步捕获`；不要声称聊天渠道内已经写入 ACT。

## 表达原则

- 标题统一用“你接下来可以回复”，每次 2—4 项即可。
- 选项必须是系统真的支持的自然语言，不展示工具名、参数或后台路径。
- 用户已经明确下一步时直接执行，不再弹菜单。
- 用户说“都不是”时，问一个短问题：“你现在是想记录、了解信息，还是整理材料？”
